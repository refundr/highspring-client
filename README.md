# Highspring Client

Remix frontend for Highspring.

## Prerequisites

- Node.js >= 20
- [Yarn](https://yarnpkg.com/) (Classic / v1)

## Setup

```bash
yarn install
```

## Development

```bash
yarn dev
```

## Build

```bash
yarn build
```

## Production

```bash
yarn start
```

## Typecheck

```bash
yarn typecheck
```
